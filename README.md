# NEXUS//BOOKS 🌌📚

A futuristic cyber-space themed digital book library built with HTML, CSS and JavaScript.

## 🚀 Features

- Futuristic dark-purple space design
- Animated stars and floating planet
- Cyberpunk navigation
- Cinematic loading screen
- Warp transition into the library
- 3D floating book cards
- Book search
- Dynamic book reader
- NEXT / PREVIOUS page navigation
- Adjustable reader font size
- Reading progress bar
- Responsive mobile design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## 📖 How It Works

1. Open the homepage
2. Enter the digital library
3. Search or choose a book
4. Click READ NOW
5. Read the selected story
6. Use NEXT and PREVIOUS to move through pages
